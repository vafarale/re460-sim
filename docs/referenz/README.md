# Referenzbilder Führerstand

Bilder des Pults der Re 460 nach Refit, die als Beleg für `src/ui/cabCatalog.ts` dienen.

Pro Bild eine Zeile in der Tabelle: Dateiname, Herkunft (Quelle, Urheber, Datum) und Nutzungsrecht.
Bilder ohne geklärtes Nutzungsrecht werden **nicht** ins Repository gelegt; dann steht hier nur
die Beschreibung, und der Katalog verweist auf diese Zeile.
